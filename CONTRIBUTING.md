# Contributing

Read [Development](Documentation/Development.md) and the scientific scope before proposing changes. Report the release label, Wolfram/dependency versions, exact command, selected model/parameters, bounded diagnostics and a minimal reproducer. Do not attach large Session/cache files containing unrelated work.

Contributions must be compatible with GPL-3.0-or-later and preserve source attribution. Distinguish implementation regressions from missing proofs/unsupported analytic domains. Pull requests should state what changed, why, the relevant validation and remaining limits.
