# External dependencies and attribution

No external software source or binaries are bundled. The GPL-3.0-or-later grant covers this project code; each separately installed dependency retains its own license and citation requirements. The GNU GPL license text in COPYING is reproduced verbatim from https://www.gnu.org/licenses/gpl-3.0.txt.

| Dependency | Use | Upstream / reference |
|---|---|---|
| Wolfram Language / Mathematica | Runtime | https://www.wolfram.com/ |
| FeynRules | Lagrangian and native vertex export | https://feynrules.irmp.ucl.ac.be/ ; arXiv:1310.1921, arXiv:0806.4194 |
| FeynCalc | D-dimensional algebra, tensor/PV reduction | https://feyncalc.github.io/ ; cite the version's official references |
| FeynArts | Fields, topologies, amplitudes and statistics | https://feynarts.de/ ; arXiv:hep-ph/0012260 |
| FeynHelpers / Package-X | Optional supported analytic pole evaluation | https://feyncalc.github.io/helpers/ ; arXiv:1611.06793, arXiv:1503.01469 |

The model/algorithm provenance is retained in the original project source headers, citation metadata and paper provenance. Generated FeynRules tensor structures remain traceable to the supplied Lagrangians. This snapshot does not claim to redistribute upstream programs or license a manuscript under the code license.
