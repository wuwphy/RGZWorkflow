# Public development / paper release checklist

## Prepared by this snapshot

- Independent source directory, GPL-3.0-or-later license and citation file.
- Explicit default model and experimental-model boundary.
- Input-only notebooks and external dependency setup.
- Version/provenance metadata, structural gate, scoped test runner and deterministic archive tool.
- Actual release test outcomes recorded separately from physics claims.

## Before associating a final paper with this code

- Confirm actual authors/copyright holders and contribution provenance.
- Fill all manuscript placeholders; freeze exact physical model and analytic conventions.
- Complete the updated-model mixed matrix and amplitude; save current fingerprints.
- Re-run full symbolic gauge comparison; record scope and complete coefficient results.
- Complete UV/IR ledgers, local CT proof and finite-part/IR interpretation for the reported result.
- Supply all machine-readable pure-loop coefficients and a reconstruction/import check.
- Independently audit free eta/auxiliary-ghost/quark propagators beyond the original 69-entry report.
- Resolve/validate experimental horizon normalization and higher-point truncation if used in the paper.
- Deposit large data with checksums; update CITATION.cff with real paper/data identifiers.
- Test on a second clean installation/platform; tag the final source and publish matching archives.

No automatic test turns these scientific/publication items into completed claims.
