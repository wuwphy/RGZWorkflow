# PT self-energy and effective charge

This is an optional research calculation. It uses the existing mixed matrices and candidate pinch workflow without changing the conventional QQ amplitude or its saved certificates. Load `Tools/PTEffectiveCharge.wl` explicitly. The mathematical functions live in the separate `RGZPTResearch` context; they do not start a PT task or certify one.

## The two-point object

The ordinary insertion between conserved A currents is

    D1_T = (D0 Pi D0)_AA = dAA^2 u_i Pi_ij u_j,
    dAA = -i A(s),
    A(s) = (s-mu^2)/[(s-m^2)(s-mu^2)+mG^4].

It is not the AA entry of the 1PI matrix alone. All ordered matrix entries and their external weights matter. The existing PT workflow stores the opposite connected coefficient,

    C_ordinary = -D1_T.

Its four candidate sectors are box, navAll, avAll and qseAll. Their multiplicities are already included. The FullMatrix NAV replaces the AA-only NAV; it must not be added to that older contribution a second time. The candidate is

    C_hat = C_ordinary + C_box + C_navAll + C_avAll + C_qseAll.

A completed `RGZPinchResult[]` contains these scalars in raw TID units. The optional function restores pole labels and multiplies by `1/(2 Pi)^4` once. Do not pass already measure-converted QQ part amplitudes as pinch kernels.

Writing the 1PI insertion as Pi=i Sigma fixes the signs:

    C_hat = i A^2 Sigma_hat,
    Sigma_hat = -i C_hat/A^2,
    Delta_M = A + A^2 Sigma_hat + O(gs^4),
    Delta_M^-1 = A^-1 - Sigma_hat + O(gs^4).

These equalities are perturbative; the rational inverse is not an all-order result. In the package's FeynArts external ordering the self-energy part of iM is `-gs^2 C_hat` times the transverse colour-current product. The two minus signs in the ordinary QQ implementation reproduce the direct Dyson insertion; no sign change to the conventional calculation is needed.

On the Euclidean sheet, s=-Q2 and Delta_E=-Delta_M(-Q2):

    K0_E(Q2) = Q2 + m^2 + mG^4/(Q2+mu^2),
    Sigma_E(Q2) = Sigma_M(-Q2),
    Delta_E^-1 = K0_E + Sigma_E,
    Delta_E = 1/K0_E - Sigma_E/K0_E^2 + O(gs^4).

## Using a completed candidate

In a dedicated FeynCalc kernel, use the existing mixed-matrix/QCD benchmark and FullMatrix PT workflow. Keep its ordinary prerequisites and staged calculations explicit:

```wolfram
RGZQCDBenchmark[600];
RGZPTStart["Mode" -> "FourPinch", "NAVMode" -> "FullMatrix"];
Do[
  RGZRunPart[name, stage, 1200],
  {name, {"box", "navAll", "avAll", "qseAll"}},
  {stage, {"Project", "Decompose", "Integrate", "Scalar"}}
];
```

Stop if a stage fails. After every sector succeeds, with `project` defined as in Start Here:

```wolfram
Get[FileNameJoin[{project, "Tools", "PTEffectiveCharge.wl"}]];
pt = RGZPinchResult[];
s = FeynCalc`FCI[FeynCalc`SPD[
  RGZWorkflow`Engine`p, RGZWorkflow`Engine`p]];
twoPoint = RGZPTResearch`RGZPTSelfEnergy[pt, s];
euclidean = RGZPTResearch`RGZPTEuclidean[twoPoint, Q2];
```

`SelfEnergyM` is the amputated candidate. `AmputationReconstruction` should be zero. A gauge-difference packet cannot supply a complete self-energy and is rejected. Gauge independence of a candidate, exact tensor reconstruction and full PT completeness are separate statements. The new functions deliberately return `PTIdentitiesVerified -> False` and `RGInvariantVerified -> False`.

## A running coupling requires a finite definition

First derive and subtract the appropriate local PT counterterms, separate UV/IR information and verify the PT renormalization identities. Unrenormalized masters are not accepted by the shape function. MOM subtraction of a massive unrenormalized ratio need not cancel all its UV divergences; it is not used as a shortcut here.

Given a finite renormalized Sigma_E, one explicit definition is

    h(Q2) = Sigma_E_R(Q2)/K0_E(Q2),
    h_MOM(Q2) = h(Q2)-h(mu0^2),
    alpha_shape(Q2) = alpha_shape(mu0^2) [1-h_MOM(Q2)]
                     + O(alpha^3).

```wolfram
shape = RGZPTResearch`RGZPTCharge[
  finiteSigmaE, Q2, euclidean["TreeInverseE"], mu0Squared, alpha0
];
```

`finiteSigmaE` must be an actual finite expression in Q2; this variable is not generated by the snippet. The function factors out the RGZ tree propagator rather than silently multiplying by Q2 or choosing an additional effective mass. This is a finite MOM shape definition with alpha0 supplied in that definition. RG invariance, process independence, threshold matching and an IR fixed point do not follow from it. Only the strict one-loop expression is returned; a geometric Dyson resummation is not presented as a higher-order calculation. The perturbative condition is `Abs[h_MOM] < 1`.

## A small calculation with actual diagrams

Run in a fresh kernel:

```sh
WolframKernel -script Examples/PTEffectiveCharge.wls
```

This generates the actual two-flavour AA quark bubble and performs its projection and integration. No pinch allocation is needed in that sector. In the stated MSbar convention it obtains

    Sigma_E_quark(Q2) = gs^2 Nf Q2/(16 Pi^2)
                       [10/9 - (2/3) log(Q2/muR2)].

The 10/9 constant includes the D-dependent coefficient times the UV pole. In the massless tree-propagator limit the induced beta coefficient is `-2 Nf/3`: the quark sector screens. The example also checks local quark-sector UV cancellation, Minkowski/Euclidean signs and subtraction-point normalization. It is one real contribution, not the full RGZ effective charge.

## The separate MSbar RG solution

The standard one-loop RG solution needs no PT decomposition:

```wolfram
running = RGZPTResearch`RGZMSbarRunning[Q2, mu0Squared, alpha0, 2, 3];
running["Alpha"]
```

It returns

    alpha_MSbar(Q2) = alpha0 /
      [1 + beta0 alpha0/(4 Pi) log(Q2/mu0Squared)],
    beta0 = 11 Nc/3 - 2 Nf/3 = 29/3 for Nc=3, Nf=2.

The convention is differentiation with respect to log(mu^2). This is a mass-independent MSbar solution; it includes no automatic RGZ threshold matching and is not an IR freezing prediction.

The distinction between an RG-invariant propagator combination and its factorization into a massive propagator and dimensionless charge is discussed in [Aguilar, Binosi and Papavassiliou, arXiv:0810.2333](https://arxiv.org/abs/0810.2333). PT identities and process independence are reviewed in [Binosi and Papavassiliou, arXiv:0909.2536](https://arxiv.org/abs/0909.2536). These results motivate the checks; they do not by themselves establish their RGZ extension.


## Numerical illustration

The saved candidate was evaluated in the Euclidean domain at the illustrative point m^2=9 Lambda^2, mu^2=Lambda^2, mG^4=25 Lambda^4, mu0^2=11 Lambda^2 and alpha0=0.20. Lambda is an arbitrary common mass unit, not a fitted QCD scale. The remaining finite bubbles are evaluated through their Feynman-parameter logarithm on the principal sheet. All mass combinations have positive real part in the integration interior.

Before continuation, both external SPD and internal Pair forms are normalized by FCI. A regression protects against leaving an uncontinued p^2 inside a master. The current finite packet has 13 distinct master structures; the earlier exploratory count of 19 included duplicate external/internal invariant representations. The normalized finite kernel agrees exactly at the illustration point with the expression used for the numerical curve.

The curve spans 0.1 <= Q/mu0 <= 10. High-precision checks at Q^2/Lambda^2=0.11, 11 and 1100 agree between 50- and 80-digit calculations, and the Euclidean imaginary residual is negligible. This is a numerical illustration of the stated candidate shape, not a fitted universal charge or an IR fixed-point determination.
